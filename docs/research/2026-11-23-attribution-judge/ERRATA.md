# Errata for `heldout.json` and `set2-policy-text.json` (2026-11-23)

The two set files are frozen: they were committed before their runs and are not edited. Their `basis` notes were written from memory and were not checked against sources when committed. Each specific was checked afterwards against a source opened on 2026-11-23. Corrections are listed here. An item's text or expected verdict is not changed; where a correction bears on an item's expected verdict, that is said.
